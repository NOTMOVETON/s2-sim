```gherkin
     SceneData.actors — vector<ActorData>
```

## AC-2: Новые YAML-поля корректно парсятся
```gherkin
Given агент в YAML имеет поля: transport, tags, immune_to_effects
When SceneLoader.load() парсит этот YAML

     AgentData.immune_to_effects содержит строки из YAML;
     AgentData.tags["transport_type"] == значение поля transport (или "ros2" если нет);
     AgentData.tags["transport_domain_id"] == domain_id из ros2-секции (или "0" если нет)
```
