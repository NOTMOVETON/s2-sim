<objective>
## Goal
Ввести абстракцию IVizAdapter и разорвать прямую зависимость SimEngine от VizServer.

## Purpose
Сейчас SimEngine знает о конкретном классе VizServer: forward-declaration в хедере,
отдельный .cpp в s2_visualizer, ODR-хак через static lib override. После этого плана:
s2_core зависит только от IVizAdapter-интерфейса; WebVizAdapter обёртывает VizServer;
NullVizAdapter позволяет тестировать без HTTP-сервера; VizRegistry фанаутит на несколько адаптеров.

## Output
Новые файлы: viz_adapter.hpp, null_viz_adapter.hpp, viz_registry.hpp (в s2_core),
web_viz_adapter.hpp + web_viz_adapter.cpp (в s2_visualizer).
Удалены: sim_engine_viz.cpp (stub в s2_core), sim_engine_viz_impl.cpp (override в s2_visualizer).
SimEngine использует IVizAdapter* вместо VizServer*.
</objective>
