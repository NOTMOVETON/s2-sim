    **actor_fsm.hpp** — утилитарный класс FSM (не IActorBehavior, используется внутри реализаций поведений):
    - `using StateId = std::string;`
    - `using EventId = std::string;`
    - `using Condition = std::function<bool()>;`
    - Struct `Transition { StateId to; Condition condition; };`
    - Class `ActorFSM`:
      - `void add_state(const StateId& s)` — регистрирует состояние
      - `void set_initial(const StateId& s)` — устанавливает начальное состояние
      - `void add_transition(const StateId& from, const EventId& event, const StateId& to, Condition cond = {})` — добавляет переход
      - `bool fire(const EventId& event)` — находит первый подходящий переход из current_state_, проверяет condition (если есть), меняет состояние; возвращает true если переход выполнен
      - `void update(double dt) {}` — хук для state-based логики (заглушка, реализации FSM дописывают свои обработчики)
      - `const StateId& current_state() const` — возвращает current_state_
    - Хранит: `StateId current_state_`, `std::unordered_map<StateId, std::unordered_map<EventId, std::vector<Transition>>>` transitions_
    - Namespace s2, header-only

    **behavior_registry.hpp** — registry типов поведений:
    - `using BehaviorFactory = std::function<std::unique_ptr<IActorBehavior>(const YAML::Node&)>;`
    - Class `BehaviorRegistry`:
      - `void register_type(const std::string& name, BehaviorFactory factory)` — регистрирует фабричную функцию
      - `std::unique_ptr<IActorBehavior> create(const std::string& type, const YAML::Node& config) const` — создаёт объект; бросает `std::runtime_error` если type не найден
      - `bool has_type(const std::string& name) const`
    - Header-only (inline impl), namespace s2
    - Паттерн аналогичен VizRegistry

    **scene_loader.hpp** — добавить загрузку behavior:
    - Добавить `#include <s2/behavior_registry.hpp>` в начало
    - Изменить сигнатуру `load()`: добавить параметр `BehaviorRegistry* behavior_registry = nullptr`
    - В секции разбора акторов (после строки `scene.actors.push_back(std::move(actor));` — ПЕРЕД push_back):
      ```cpp
      if (actor_node["behavior"] && behavior_registry) {
          auto btype = actor_node["behavior"]["type"].as<std::string>();
          auto bcfg  = actor_node["behavior"]["config"]
                           ? actor_node["behavior"]["config"]
                           : YAML::Node{};
          actor.behavior = behavior_registry->create(btype, bcfg);
          actor.behavior->on_init(bcfg);
      }
      ```
    - Не менять ничего вне секции акторов и сигнатуры load()
