# Задача 20.1 — Выравнивание ориентации агента по опорной поверхности

## Цель

При движении по наклонной поверхности агент должен визуально наклоняться (pitch и roll)
в соответствии с нормалью поверхности под ним. Сейчас pitch и roll всегда равны 0.

## Зависимости

- Задача 20 (CollisionSystem) — завершена. Использует данные из `check_sphere_all()`.

## Принятые решения

| Вопрос | Решение |
|--------|---------|
| Источник нормали | `CollisionContact.contact_normal` из уже вычисленных контактов (фаза 3h) |
| Нормаль какого контакта | Первый walkable-контакт (наибольшая penetration, т.к. contacts отсортированы) |
| При отсутствии опоры | Сброс pitch=roll=0 (агент в воздухе или только у стен) |
| Сглаживание | Нет (50Hz обновление даёт плавность при постепенном въезде на пандус) |
| Влияние на yaw | Нет — yaw определяется diff_drive, не поверхностью |

## Архитектура

### Текущее состояние

- `Pose3D` (types.hpp) имеет поля `roll`, `pitch`, `yaw`
- В `sim_engine.hpp` только `yaw` обновляется (`yaw += wz * dt_`)
- `roll` и `pitch` никогда не меняются — всегда 0
- Фронтенд (`app.js`) уже применяет все три угла: `rotation.set(pose.roll, pose.yaw, -pose.pitch, 'YZX')`
- `check_sphere_all()` возвращает `contact_normal` — нормаль поверхности в мировых координатах

### Математика

Из нормали поверхности `n = (nx, ny, nz)` (ZYX-конвенция, Rz×Ry×Rx):

```
roll  = atan2(-ny, nz)   // наклон вокруг X (YZ-плоскость)
pitch = atan2( nx, nz)   // наклон вокруг Y (XZ-плоскость)
```

Проверка для пандуса roll=-15° (нормаль = (0, 0.259, 0.966)):
- `roll  = atan2(-0.259, 0.966) = -15°` ✓
- `pitch = atan2(0, 0.966)      = 0°`   ✓

Горизонтальный пол (нормаль = (0, 0, 1)):
- `roll = pitch = 0` ✓

## Реализация

### Единственный изменяемый файл: `workspace/s2_core/include/s2/sim_engine.hpp`

В фазе 3h, после цикла обработки коллизий, добавить секцию выравнивания ориентации
(внутри `if (agent.has_collision && agent.bounding.type == ShapeType::SPHERE)`):

```cpp
// === Выравнивание по опорной поверхности ===
bool surface_found = false;
for (const auto& contact : contacts) {
    bool walkable = contact.contact_normal.z() >=
                    std::cos(agent.max_slope_rad);
    if (walkable) {
        const Vec3& n = contact.contact_normal;
        agent.world_pose.roll  = std::atan2(-n.y(), n.z());
        agent.world_pose.pitch = std::atan2( n.x(), n.z());
        surface_found = true;
        break;
    }
}
if (!surface_found) {
    agent.world_pose.roll  = 0.0;
    agent.world_pose.pitch = 0.0;
}
```
