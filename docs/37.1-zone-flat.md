# Задача 37.1 — 2D зоны (FLAT shape type)

## Цель

Добавить тип зоны `FLAT` — плоская зона с произвольной ориентацией в 3D пространстве.
Принципиальное отличие от существующих типов (SPHERE, AABB, CYLINDER): зона математически двумерна.
Она лежит в плоскости, заданной нормалью, и агент попадает в неё только при физическом касании этой плоскости.

Примеры применения:
- Ледяная разметка на полу (нормаль вверх, `normal = {0, 0, 1}`)
- Зона трения на наклонной рампе (нормаль перпендикулярна рампе)
- Маркировка на стене (нормаль горизонтальная, `normal = {1, 0, 0}`)
- Зона на потолке для дрона при посадке сверху (нормаль вниз)

## Зависимости

- Задача 23 (ZoneSystem инфраструктура, ZoneShape::contains())
- Задача 24 (MODIFIER эффекты — для тестового примера с ледяной зоной)

## Концепт: математика FLAT зоны

### Геометрическое определение

FLAT зона задаётся:
- `center` — точка на плоскости (Vec3)
- `normal` — единичная нормаль к плоскости (Vec3, **должна быть нормализована**)
- Двумерная форма на плоскости: `radius` (круг) или `half_size.x/y` (прямоугольник)
- `contact_epsilon` — толщина "контактного слоя" (метры)

Уравнение плоскости: `dot(P - center, normal) = 0`

### Алгоритм contains() для FLAT

Проверка "агент в зоне" состоит из двух независимых условий:

**Шаг 1 — Расстояние до плоскости (contact check):**
```
dist_signed = dot(point - center, normal)
```
Агент "касается" плоскости если:
```
|dist_signed| <= contact_epsilon
```
Это аналог: агент должен находиться в тонком слое толщиной `2 * contact_epsilon`
симметрично относительно плоскости.

Если условие не выполнено → `contains() = false`. Дальнейшая проверка не нужна.

**Шаг 2 — Принадлежность проекции к 2D форме:**

Проецируем точку на плоскость:
```
proj = point - dist_signed * normal
```
`proj` — ближайшая точка на плоскости к `point`.

Вычитаем центр зоны (переходим в систему координат плоскости):
```
diff = proj - center
```

Вычисляем координаты в локальном базисе плоскости:
```
// Выбираем произвольный ортонормальный базис в плоскости
// tangent1 и tangent2 — два вектора, перпендикулярных normal и друг другу
tangent1 = (abs(normal.z()) < 0.9) ? normal.cross(Vec3(0,0,1)).normalized()
                                    : normal.cross(Vec3(1,0,0)).normalized()
tangent2 = normal.cross(tangent1)

u = diff.dot(tangent1)  // "x" в системе плоскости
v = diff.dot(tangent2)  // "y" в системе плоскости
```

Для **круглой зоны** (задаётся через `radius`):
```
return u*u + v*v <= radius * radius
```

Для **прямоугольной зоны** (задаётся через `half_size.x()` и `half_size.y()`):
```
return abs(u) <= half_size.x() && abs(v) <= half_size.y()
```

### Важный edge case: вертикальность нормали

При выборе `tangent1` нельзя брать cross с коллинеарным вектором — результат будет нулевым.
Поэтому используем fallback:
- Если `|normal.z()| < 0.9` → `tangent1 = cross(normal, (0,0,1)).normalized()`
- Иначе (нормаль почти вертикальная) → `tangent1 = cross(normal, (1,0,0)).normalized()`

### Примеры

**Горизонтальная зона на полу (z=0):**
```
normal = {0, 0, 1}
center = {5, 5, 0}
radius = 2.0
contact_epsilon = 0.05
```
Робот с `world_pose.z = 0.03` → `|dist| = 0.03 < 0.05` → проходит шаг 1.
Дрон с `world_pose.z = 0.1` → `|dist| = 0.1 > 0.05` → не проходит, не в зоне.

**Зона на стене (x=5):**
```
normal = {1, 0, 0}
center = {5, 0, 1}
half_size = {2.0, 1.5, 0}  // x → вдоль стены по Y, y → по Z
contact_epsilon = 0.03
```
Агент в `{5.02, 1.0, 0.8}` → `dist = 0.02 < 0.03` → проходит шаг 1.
Проекция попадает в прямоугольник → в зоне.

**Зона на наклонной рампе (45°):**
```
normal = {sin(45°), 0, cos(45°)} = {0.707, 0, 0.707}
center = {3, 0, 3}
radius = 1.5
contact_epsilon = 0.05
```

### 2. Расширить ZoneShape: поля normal и contact_epsilon

**Файл:** `workspace/s2_core/include/s2/types.hpp`

```cpp
struct ZoneShape
{
  ZoneShapeType type{ZoneShapeType::SPHERE};
  Vec3  center{Vec3::Zero()};
  double radius{1.0};
  Vec3  half_size{1.0, 1.0, 1.0};
  double half_height{1.0};

  // ── FLAT-специфичные поля ──────────────────────────────────────────
  /// Нормаль к плоскости зоны. Должна быть единичной (нормализованной).
  /// Используется только для ZoneShapeType::FLAT.
  /// Примеры: {0,0,1} = горизонтальный пол, {1,0,0} = вертикальная стена Y-Z,
  ///          {0,0,-1} = потолок, {0.707,0,0.707} = наклонная поверхность 45°.
  Vec3 normal{0.0, 0.0, 1.0};

  /// Допуск касания для FLAT зоны (метры).
  /// Агент "касается" плоскости если расстояние до неё < contact_epsilon.
  /// По умолчанию 5 см — достаточно для колёсного робота на полу с физикой.
  /// Уменьшить для стен/потолка где нужна точность.
  double contact_epsilon{0.05};

  bool contains(const Vec3& point) const { ... }
};
```

### 3. Реализовать contains() для FLAT

**Файл:** `workspace/s2_core/include/s2/types.hpp`

Добавить ветку в `ZoneShape::contains()`:

```cpp
case ZoneShapeType::FLAT: {
    // Шаг 1: расстояние до плоскости
    double dist = (point - center).dot(normal);
    if (std::abs(dist) > contact_epsilon)
        return false;

    // Шаг 2: проекция на плоскость и проверка 2D формы
    // proj — ближайшая точка на плоскости к point
    Vec3 diff = (point - dist * normal) - center;

    // Строим ортонормальный базис в плоскости
    Vec3 t1 = (std::abs(normal.z()) < 0.9)
        ? normal.cross(Vec3(0, 0, 1)).normalized()
        : normal.cross(Vec3(1, 0, 0)).normalized();
    Vec3 t2 = normal.cross(t1);  // уже нормализован (normal и t1 единичные и ⊥)

    double u = diff.dot(t1);
    double v = diff.dot(t2);

    // Если задан radius (круглая зона): проверяем диск
    // Если задан half_size.x/y (прямоугольная): проверяем прямоугольник
    // Различаем по наличию radius > 0 vs half_size != default
    // В YAML: "radius: N" → круг, "half_size: {x, y}" → прямоугольник
    if (radius > 0.0) {
        return u * u + v * v <= radius * radius;
    } else {
        return std::abs(u) <= half_size.x() && std::abs(v) <= half_size.y();
    }
}
```

**Примечание:** Если в YAML задан `radius`, он хранится в поле `radius` (как для SPHERE).
`half_size.x/y` используются для прямоугольных 2D зон. Оба не задаются одновременно.

### 4. Парсинг FLAT зоны в SceneLoader

**Файл:** `workspace/s2_core/src/scene_loader.cpp`

В функции парсинга формы зоны добавить ветку:

```cpp
if (shape_type == "flat") {
    shape.type = ZoneShapeType::FLAT;

    // normal — обязательный параметр для FLAT зоны
    if (shape_node["normal"]) {
        shape.normal.x() = shape_node["normal"]["x"].as<double>(0.0);
        shape.normal.y() = shape_node["normal"]["y"].as<double>(0.0);
        shape.normal.z() = shape_node["normal"]["z"].as<double>(1.0);
        // Нормализуем на случай если пользователь задал ненормализованный вектор
        double len = shape.normal.norm();
        if (len > 1e-6) shape.normal /= len;
    }

    // contact_epsilon — опциональный, default 0.05
    shape.contact_epsilon = shape_node["contact_epsilon"].as<double>(0.05);

    // Форма на плоскости: radius (круг) или half_size (прямоугольник)
    if (shape_node["radius"]) {
        shape.radius = shape_node["radius"].as<double>(1.0);
    } else if (shape_node["half_size"]) {
        shape.half_size.x() = shape_node["half_size"]["x"].as<double>(1.0);
        shape.half_size.y() = shape_node["half_size"]["y"].as<double>(1.0);
        shape.radius = 0.0;  // явно обнуляем чтобы contains() знал что это прямоугольник
    }
}
```
