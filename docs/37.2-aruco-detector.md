# Задача 37.2 — ArucoSignal на объектах + ArucoDetectorPlugin

## Цель

Ввести механизм сигналов на объектах сцены и реализовать первый детектор на его основе.

**Ключевая идея:** ArUco маркер — это не отдельный объект мира, а сигнал, который объект
(пропп, актор, агент) несёт на себе. Бочка с наклеенным маркером, дверь с QR-кодом,
робот с маркером на корпусе — это один и тот же механизм. Детектор сканирует все объекты
и проверяет: несёт ли этот объект сигнал нужного типа? Виден ли он?

**Зачем отдельно от типа объекта:** маркер — это наблюдаемое свойство (что объект "показывает"
вовне), а не его физическая суть (что он "делает"). Одна и та же бочка может нести маркер
или не нести — это не меняет её физическое поведение.

**Dual-zone модель детекции:** обнаружение происходит только при пересечении двух зон:
1. Зона видимости маркера — насколько далеко физически виден данный маркер (зависит от его размера)
2. Зона чувствительности детектора — насколько далеко детектор способен воспринимать маркеры
   (зависит от качества камеры)

Это первый detector-плагин в системе. Он закладывает инфраструктуру восприятия:
Detection Volume, LoS, relative pose, publish_rate_hz, результат в SharedState.
Задачи 37.3–37.5 используют тот же паттерн.

## Концепт: механизм сигналов

### Что такое сигнал (ArucoSignal)

`ArucoSignal` — декларативное свойство, которое объект несёт и которое можно наблюдать
через физический канал (в данном случае — визуальный: требует LoS).

Ключевые параметры:
- `marker_id` — стандартный ArUco ID, смысловая нагрузка
- `size` — физический размер стороны маркера [м]. Именно этот параметр определяет
  с какого максимального расстояния маркер вообще может быть замечен
- `local_pose` — поза маркера относительно объекта-носителя

### Dual-zone модель: как работает дальность обнаружения

Дрон с хорошей камерой видит маркер 0.15 м на 10 м. Робот с плохой камерой видит тот же
маркер только на 3 м. Но большой маркер 0.5 м и плохая камера видит дальше.

Физическая модель: камера разрешает угол. Маркер вдвое большего размера виден вдвое дальше.

```
effective_range = detection_range * (marker.size / reference_marker_size)
```

Где:
- `detection_range` — максимальная дальность детектора для маркера эталонного размера
- `reference_marker_size` — эталонный размер при калибровке (по умолчанию 0.15 м)
- `marker.size` — фактический физический размер маркера

Пример:
- Детектор: detection_range=10, reference_size=0.15
- Маркер 0.15 м → effective_range = 10 м
- Маркер 0.30 м → effective_range = 20 м
- Маркер 0.05 м → effective_range = 3.3 м

Дрон с зумом: detection_range=20 (видит 0.15 м маркер с 20 м).
Плохая камера: detection_range=3 (видит 0.15 м маркер только с 3 м).

### Detection Volume

Область пространства, в которой детектор вообще ищет цели. Три типа:

**SPHERE** — omnidirectional, все направления:
```
dist(agent_pos, target_pos) <= effective_range
```

**CONE** — направленная камера вперёд:
```
dist <= effective_range
  AND
(target_pos - agent_pos).normalized().dot(forward) >= cos(fov_angle / 2)
```
Где `forward = R * Vec3(1, 0, 0)`, R — матрица вращения агента.

**CYLINDER** — дрон с камерой вниз:
```
sqrt(dx² + dy²) <= effective_range
  AND
|dz| <= cylinder_half_height
```

### Line-of-Sight (LoS)

Визуальный канал — маркер за стеной не виден.

```cpp
Vec3 origin    = agent.world_pose.position();
Vec3 target    = signal_world_pos;     // поза маркера в мировых координатах
Vec3 diff      = target - origin;
double dist    = diff.norm();

Ray ray{origin, diff.normalized(), dist};
RaycastResult result = raycast_->cast(ray);

const double LOS_EPSILON = 0.05;
bool los_clear = !result.hit || (result.distance >= dist - LOS_EPSILON);
```

Маркер сам по себе не является коллизионным объектом — он не добавляется в raycast-геометрию.
Луч проверяет только стены и другие коллизии.

### Поза маркера в мировых координатах

Маркер хранит `local_pose` — позу относительно объекта-носителя. Для LoS и relative_pose
нужна мировая поза маркера:

```cpp
// Мировая поза носителя (пропп, актор, агент)
Pose3D carrier_world_pose = carrier.world_pose;

// Мировая поза маркера = поза носителя + локальная поза маркера
// (упрощённо: для задач без сложной ориентации носителя достаточно сложения позиций)
Vec3 signal_world_pos = carrier_world_pose.position() + signal.local_pose.position();
```

Для полной точности нужна матрица вращения носителя:
```cpp
Eigen::Matrix3d R_carrier = CollisionSystem::rotation_from_pose(carrier_world_pose);
Vec3 signal_world_pos = carrier_world_pose.position()
                      + R_carrier * signal.local_pose.position();
```

### Relative Pose

Поза маркера в системе координат тела агента-наблюдателя:

```cpp
Eigen::Matrix3d R_obs = CollisionSystem::rotation_from_pose(agent.world_pose);
Vec3 world_vec  = signal_world_pos - agent.world_pose.position();
Vec3 local_vec  = R_obs.transpose() * world_vec;

relative_pose.x     = local_vec.x();
relative_pose.y     = local_vec.y();
relative_pose.z     = local_vec.z();
relative_pose.yaw   = std::atan2(local_vec.y(), local_vec.x());
relative_pose.pitch = std::atan2(-local_vec.z(),
                          std::sqrt(local_vec.x()*local_vec.x()
                                  + local_vec.y()*local_vec.y()));
```

### source_type и source_id в результате

Детектор видит маркер — но на каком объекте он находится? Это важно для принятия решений:
"маркер 42 на пропе #3 (паллете) в 5 м слева" — качественно другая информация
чем просто "маркер 42 в 5 м слева".

В `ArucoDetection` добавляем:
- `source_type` — "prop", "actor", "agent"
- `source_id` — id объекта-носителя

```cpp
/**
 * @brief Сигнал ArUco маркера на объекте-носителе.
 *
 * Декларируется на объектах сцены (Prop, Actor, Agent) для обозначения
 * того, что данный объект несёт ArUco маркер. Детектор сканирует все
 * объекты и проверяет наличие этого сигнала.
 *
 * Параметры:
 *  - marker_id:  ArUco ID (0–249 для ARUCO_4X4_250)
 *  - size:       физический размер стороны маркера [м].
 *                Определяет максимальную дальность видимости:
 *                больший маркер виден с бо́льшего расстояния.
 *  - local_pose: положение и ориентация маркера относительно носителя.
 *                {0,0,0} = совпадает с origin носителя.
 */
struct ArucoSignal {
    uint32_t marker_id{0};
    double   size{0.15};
    Pose3D   local_pose;
};
```

### 3. Типы результата детекции

**Файл:** `workspace/s2_core/include/s2/sensor_data.hpp`

```cpp
/**
 * @brief Одно обнаружение ArUco маркера.
 *
 * source_type: тип объекта-носителя маркера ("prop", "actor", "agent")
 * source_id:   идентификатор объекта-носителя
 * marker_id:   стандартный ArUco ID маркера
 * relative_pose: поза маркера в системе координат тела наблюдателя
 * distance:    евклидово расстояние до маркера [м]
 */
struct ArucoDetection {
    std::string source_type;
    uint32_t    source_id{0};
    uint32_t    marker_id{0};
    Pose3D      relative_pose;
    double      distance{0.0};
};

/**
 * @brief Результат работы ArucoDetectorPlugin за один цикл публикации.
 *
 * seq: монотонно растущий счётчик публикаций.
 * detections: список всех видимых маркеров. Пустой если ни один не виден.
 */
struct ArucoDetectionData {
    uint64_t seq{0};
    std::vector<ArucoDetection> detections;
};
```

### 6. ArucoDetectorPlugin — основной плагин

**Файл:** `workspace/s2_plugins/include/s2/plugins/aruco_detector.hpp` (новый)

```cpp
#pragma once

#include <s2/plugin_base.hpp>
#include <s2/sensor_data.hpp>
#include <s2/agent.hpp>
#include <s2/prop.hpp>
#include <s2/actor.hpp>
#include <s2/collision_system.hpp>
#include <s2/raycast_engine.hpp>
#include <yaml-cpp/yaml.h>
#include <cmath>

namespace s2::plugins {

/**
 * @brief Плагин-детектор ArUco маркеров.
 *
 * Сканирует все объекты мира (пропы, акторы, агентов) на наличие aruco_signals.
 * Для каждого найденного маркера проверяет:
 *   1. Detection Volume (sphere / cone / cylinder)
 *   2. Dual-zone дальность: effective_range = detection_range * (size / ref_size)
 *   3. Line-of-Sight через RaycastEngine
 *
 * Результат — ArucoDetectionData в SharedState агента.
 *
 * Параметры:
 *  - volume_type:           тип Detection Volume ("sphere" | "cone" | "cylinder")
 *  - detection_range:       максимальная дальность [м] для маркера reference_size
 *  - reference_marker_size: эталонный размер маркера [м], default 0.15
 *  - fov_angle:             угол обзора для "cone" [градусы, полный угол конуса]
 *  - cylinder_half_height:  полувысота для "cylinder" [м]
 *  - publish_rate_hz:       частота публикации результатов [Гц]
 */
class ArucoDetectorPlugin : public IAgentPlugin {
public:
    std::string type() const override { return "aruco_detector"; }

    void from_config(const YAML::Node& node) override {
        volume_type_           = node["volume_type"].as<std::string>("sphere");
        detection_range_       = node["detection_range"].as<double>(5.0);
        reference_marker_size_ = node["reference_marker_size"].as<double>(0.15);
        publish_rate_hz_       = node["publish_rate_hz"].as<double>(10.0);
        cylinder_half_height_  = node["cylinder_half_height"].as<double>(2.0);

        double fov_deg = node["fov_angle"].as<double>(360.0);
        fov_half_cos_  = std::cos((fov_deg / 2.0) * M_PI / 180.0);
    }

    void set_raycast_engine(const RaycastEngine* e) override { raycast_ = e; }
    void set_props(const std::vector<Prop>* p)   override { props_  = p; }
    void set_agents(const std::vector<Agent>* a) override { agents_ = a; }
    void set_actors(const std::vector<Actor>* a) override { actors_ = a; }

    void update(double dt, Agent& agent) override {
        publish_timer_ += dt;
        if (publish_rate_hz_ > 0 && publish_timer_ < 1.0 / publish_rate_hz_)
            return;
        publish_timer_ = 0.0;

        ArucoDetectionData data;
        data.seq = seq_++;

        if (!raycast_) {
            agent.state.emplace<ArucoDetectionData>(std::move(data));
            return;
        }

        const Vec3 agent_pos = agent.world_pose.position();
        const Eigen::Matrix3d R_obs = CollisionSystem::rotation_from_pose(agent.world_pose);
        const Vec3 forward = R_obs * Vec3(1.0, 0.0, 0.0);

        // Сканируем пропы
        if (props_) {
            for (const auto& prop : *props_) {
                for (const auto& sig : prop.aruco_signals) {
                    try_detect(sig, prop.world_pose, "prop", prop.id,
                               agent, agent_pos, R_obs, forward, data);
                }
            }
        }

        // Сканируем акторов
        if (actors_) {
            for (const auto& actor : *actors_) {
                for (const auto& sig : actor.aruco_signals) {
                    try_detect(sig, actor.world_pose, "actor", actor.id,
                               agent, agent_pos, R_obs, forward, data);
                }
            }
        }

        // Сканируем агентов (кроме самого себя)
        if (agents_) {
            for (const auto& other : *agents_) {
                if (other.id == agent.id) continue;
                for (const auto& sig : other.aruco_signals) {
                    try_detect(sig, other.world_pose, "agent", other.id,
                               agent, agent_pos, R_obs, forward, data);
                }
            }
        }

        agent.state.emplace<ArucoDetectionData>(std::move(data));
    }

    std::string to_json() const override { return "{}"; }

    void contribute_snapshot(nlohmann::json& out, const Agent& agent) const override {
        const auto* data = agent.state.get<ArucoDetectionData>();
        if (!data) return;
        nlohmann::json arr = nlohmann::json::array();
        for (const auto& d : data->detections) {
            arr.push_back({
                {"marker_id",   d.marker_id},
                {"source_type", d.source_type},
                {"source_id",   d.source_id},
                {"distance",    d.distance},
                {"x",     d.relative_pose.x},
                {"y",     d.relative_pose.y},
                {"z",     d.relative_pose.z},
                {"yaw",   d.relative_pose.yaw},
                {"pitch", d.relative_pose.pitch}
            });
        }
        out["aruco_detections"] = arr;
    }

private:
    // Проверить один сигнал на одном объекте-носителе
    void try_detect(const ArucoSignal& sig,
                    const Pose3D& carrier_pose,
                    const std::string& source_type,
                    uint32_t source_id,
                    const Agent& agent,
                    const Vec3& agent_pos,
                    const Eigen::Matrix3d& R_obs,
                    const Vec3& forward,
                    ArucoDetectionData& data) const
    {
        // Мировая поза маркера
        Eigen::Matrix3d R_carrier = CollisionSystem::rotation_from_pose(carrier_pose);
        Vec3 signal_world_pos = carrier_pose.position()
                              + R_carrier * sig.local_pose.position();

        const Vec3 diff = signal_world_pos - agent_pos;
        const double dist = diff.norm();

        // Dual-zone: effective_range по физическому размеру маркера
        double effective_range = detection_range_;
        if (reference_marker_size_ > 1e-9)
            effective_range = detection_range_ * (sig.size / reference_marker_size_);

        if (!in_detection_volume(diff, dist, effective_range, forward))
            return;

        // LoS
        if (dist > 1e-6) {
            const double LOS_EPSILON = 0.05;
            Ray ray{agent_pos, diff.normalized(), dist};
            RaycastResult res = raycast_->cast(ray);
            if (res.hit && res.distance < dist - LOS_EPSILON)
                return;
        }

        // Relative pose в системе координат тела агента
        Vec3 local_vec = R_obs.transpose() * diff;

        ArucoDetection det;
        det.source_type = source_type;
        det.source_id   = source_id;
        det.marker_id   = sig.marker_id;
        det.distance    = dist;
        det.relative_pose.x     = local_vec.x();
        det.relative_pose.y     = local_vec.y();
        det.relative_pose.z     = local_vec.z();
        det.relative_pose.yaw   = std::atan2(local_vec.y(), local_vec.x());
        det.relative_pose.pitch = std::atan2(-local_vec.z(),
            std::sqrt(local_vec.x()*local_vec.x() + local_vec.y()*local_vec.y()));
        det.relative_pose.roll  = 0.0;

        data.detections.push_back(std::move(det));
    }

    bool in_detection_volume(const Vec3& diff, double dist,
                             double effective_range, const Vec3& forward) const
    {
        if (volume_type_ == "sphere") {
            return dist <= effective_range;
        }
        else if (volume_type_ == "cone") {
            if (dist > effective_range) return false;
            if (dist < 1e-9) return true;
            return diff.normalized().dot(forward) >= fov_half_cos_;
        }
        else if (volume_type_ == "cylinder") {
            double horiz2 = diff.x()*diff.x() + diff.y()*diff.y();
            return horiz2 <= effective_range * effective_range
                && std::abs(diff.z()) <= cylinder_half_height_;
        }
        return false;
    }

    std::string volume_type_{"sphere"};
    double detection_range_{5.0};
    double reference_marker_size_{0.15};
    double fov_half_cos_{-1.0};
    double cylinder_half_height_{2.0};
    double publish_rate_hz_{10.0};
    double publish_timer_{0.0};
    uint64_t seq_{0};

    const RaycastEngine*       raycast_{nullptr};
    const std::vector<Prop>*   props_{nullptr};
    const std::vector<Actor>*  actors_{nullptr};
    const std::vector<Agent>*  agents_{nullptr};
};

} // namespace s2::plugins
```

### 8. SceneLoader: парсинг aruco_signals

**Файл:** `workspace/s2_core/src/scene_loader.cpp`

Вспомогательная функция для парсинга сигналов (используется для пропов, акторов, агентов):

```cpp
// Вспомогательная функция
static void parse_aruco_signals(const YAML::Node& node,
                                 std::vector<ArucoSignal>& out)
{
    if (!node["aruco_signals"]) return;
    for (const auto& sn : node["aruco_signals"]) {
        ArucoSignal sig;
        sig.marker_id = sn["marker_id"].as<uint32_t>(0);
        sig.size      = sn["size"].as<double>(0.15);
        if (sn["local_pose"]) {
            sig.local_pose.x     = sn["local_pose"]["x"].as<double>(0.0);
            sig.local_pose.y     = sn["local_pose"]["y"].as<double>(0.0);
            sig.local_pose.z     = sn["local_pose"]["z"].as<double>(0.0);
            sig.local_pose.yaw   = sn["local_pose"]["yaw"].as<double>(0.0);
            sig.local_pose.pitch = sn["local_pose"]["pitch"].as<double>(0.0);
        }
        out.push_back(std::move(sig));
    }
}
```

Вызывается при парсинге каждого типа объекта:
```cpp
// При загрузке пропа:
parse_aruco_signals(prop_node, prop.aruco_signals);

// При загрузке актора:
parse_aruco_signals(actor_node, actor.aruco_signals);

// При загрузке агента:

```

### 9. WorldSnapshot: маркеры как часть объектов

Отдельный список `aruco_markers` в снапшоте больше не нужен. Визуализатор
получает информацию о маркерах через снапшоты пропов, акторов и агентов, которые
уже содержат `aruco_signals` (или визуализатор вычисляет мировую позу маркера из
позы носителя + local_pose).

Если визуализатору нужны маркеры как отдельный список для отрисовки, `build_snapshot()`
вычисляет мировые позы за один проход по всем носителям:

```cpp
// В build_snapshot():
for (const auto& prop : world_.props()) {
    Eigen::Matrix3d R = CollisionSystem::rotation_from_pose(prop.world_pose);
    for (const auto& sig : prop.aruco_signals) {
        ArucoMarkerSnapshot ms;
        ms.marker_id = sig.marker_id;
        ms.pose.x    = prop.world_pose.x + (R * sig.local_pose.position()).x();
        ms.pose.y    = prop.world_pose.y + (R * sig.local_pose.position()).y();
        ms.pose.z    = prop.world_pose.z + (R * sig.local_pose.position()).z();
        ms.size      = sig.size;
        snap.aruco_markers.push_back(ms);
    }
}
// Аналогично для акторов и агентов
```
