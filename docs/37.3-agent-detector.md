# Задача 37.3 — AgentDetectorPlugin — детекция других роботов

## Цель

Плагин-наблюдатель: агент видит других агентов в своём Detection Volume с учётом LoS.
Результат включает не только позицию, но и bounding box и скорость цели — всё что
нужно для принятия решений (планирование объезда, следование за роботом, и т.д.).

## Зависимости

- Задача 37.2 (ArucoDetectorPlugin — паттерн detector-плагина, Detection Volume + LoS)
- `plugin_base.hpp` — `IAgentPlugin`, `set_agents()` добавляется здесь же

## Концепт: отличия от ArucoDetectorPlugin

### Что нового по сравнению с 37.2

**1. Источник данных — другие агенты, а не пропы.**
`set_agents(const std::vector<Agent>*)` — по образцу `set_props` из задачи 37.2.
Агент не видит сам себя: пропускаем `if (other.id == agent.id) continue`.

**2. LoS использует bounding capsule других агентов.**
RaycastEngine уже имеет динамических агентов в `dynamic_prims_`. Но они добавляются в SimEngine
для текущего агента-владельца лидара — другие агенты как preims. То же работает здесь:
`cast()` проверяет как статику (стены), так и bounding других агентов.

Однако есть тонкость: LoS от A до B может быть "заблокирован" самим B (его bounding).
Чтобы этого избежать, луч должен останавливаться чуть раньше цели:
```cpp
// Останавливаем луч в 2*radius цели раньше — не попадаем в саму цель
double safe_dist = dist - target_agent.bounding.radius * 2.0 - LOS_EPSILON;
if (safe_dist < 0) safe_dist = 0;
Ray ray{origin, direction, safe_dist};
```

**3. Результат включает bounding box и velocity.**
Bounding box нужен для объезда и оценки размера цели.
Velocity нужна для предсказания движения (relative velocity).

**4. Capabilities filter.**
Агент-детектор может видеть только агентов с определёнными capabilities:
`required_target_capabilities: ["visible"]` — видит только тех у кого есть `"visible"`.
Пустой список = видит всех.

### Bounding box в результате

Агент хранит `bounding: CollisionShape` — это его коллизионный шейп.
В результате детекции передаём размеры в мировых единицах:

```cpp
// Для SPHERE: x/y/z = diameter (2*radius)
// Для BOX: x/y/z = full extents (2*half_extents)
Vec3 bbox_full_extents;
if (target.bounding.type == ShapeType::SPHERE) {
    double d = target.bounding.radius * 2.0;
    bbox_full_extents = Vec3{d, d, d};
} else {
    bbox_full_extents = target.bounding.size * 2.0;
}
```

### Relative velocity

Скорость цели в системе координат наблюдателя:

```cpp
// world_velocity цели — в локальных координатах тела цели
// Переводим в мировые:
Eigen::Matrix3d R_target = CollisionSystem::rotation_from_pose(target.world_pose);
Vec3 target_world_vel = R_target * target.world_velocity.linear;

// Переводим в тело наблюдателя:
Eigen::Matrix3d R_obs = CollisionSystem::rotation_from_pose(agent.world_pose);
Vec3 relative_vel_world = target_world_vel - R_obs * agent.world_velocity.linear;
Vec3 relative_vel_local = R_obs.transpose() * relative_vel_world;
```

Отрицательный `relative_vel_local.x()` = цель движется к наблюдателю вдоль его оси X.

## Что сделать

### 1. Типы результата

**Файл:** `workspace/s2_core/include/s2/sensor_data.hpp`

```cpp
/**
 * @brief Одно обнаружение другого агента.
 *
 * relative_pose: поза цели в системе координат тела наблюдателя
 * bounding_extents: полные размеры bounding box цели [м] (diameter для сферы)
 * relative_velocity: скорость цели в системе координат тела наблюдателя [м/с]
 * distance: евклидово расстояние между центрами [м]
 */
struct AgentDetection {
    AgentId  target_id{0};
    Pose3D   relative_pose;
    Vec3     bounding_extents{Vec3::Zero()};
    Vec3     relative_velocity{Vec3::Zero()};
    double   distance{0.0};
};

struct AgentDetectionData {
    uint64_t seq{0};
    std::vector<AgentDetection> detections;
};
```

### 4. AgentDetectorPlugin

**Файл:** `workspace/s2_plugins/include/s2/plugins/agent_detector.hpp` (новый)

```cpp
#pragma once

#include <s2/plugin_base.hpp>
#include <s2/agent.hpp>
#include <s2/sensor_data.hpp>
#include <s2/collision_system.hpp>
#include <s2/raycast_engine.hpp>
#include <yaml-cpp/yaml.h>
#include <vector>
#include <string>

namespace s2::plugins {

/**
 * @brief Плагин-детектор других агентов (роботов).
 *
 * Видит других агентов в Detection Volume с учётом LoS.
 * Не видит сам себя (фильтр по agent.id).
 *
 * Параметры:
 *  - volume_type, detection_range, fov_angle, cylinder_half_height — как в ArucoDetector
 *  - required_target_capabilities: список capabilities, которые должны быть у цели.
 *    Пустой список = видеть всех агентов.
 *    Пример: ["visible"] — видеть только агентов помеченных как видимые.
 */
class AgentDetectorPlugin : public IAgentPlugin {
public:
    std::string type() const override { return "agent_detector"; }

    void from_config(const YAML::Node& node) override {
        volume_type_     = node["volume_type"].as<std::string>("sphere");
        detection_range_ = node["detection_range"].as<double>(10.0);
        publish_rate_hz_ = node["publish_rate_hz"].as<double>(5.0);

        double fov_deg = node["fov_angle"].as<double>(360.0);
        fov_half_cos_  = std::cos((fov_deg / 2.0) * M_PI / 180.0);

        cylinder_half_height_ = node["cylinder_half_height"].as<double>(2.0);

        if (node["required_target_capabilities"]) {
            for (const auto& cap : node["required_target_capabilities"])
                required_caps_.push_back(cap.as<std::string>());
        }
    }

    void set_raycast_engine(const RaycastEngine* e) override { raycast_ = e; }
    void set_agents(const std::vector<Agent>* a) override { agents_ = a; }

    void update(double dt, Agent& agent) override {
        publish_timer_ += dt;
        if (publish_rate_hz_ > 0 && publish_timer_ < 1.0 / publish_rate_hz_)
            return;
        publish_timer_ = 0.0;

        AgentDetectionData data;
        data.seq = seq_++;

        if (!agents_ || !raycast_) {
            agent.state.emplace<AgentDetectionData>(std::move(data));
            return;
        }

        const Vec3 agent_pos = agent.world_pose.position();
        const Eigen::Matrix3d R_obs = CollisionSystem::rotation_from_pose(agent.world_pose);
        const Vec3 forward = R_obs * Vec3(1.0, 0.0, 0.0);

        for (const auto& target : *agents_) {
            // Не видим себя
            if (target.id == agent.id) continue;

            // Фильтр по capabilities цели
            if (!required_caps_.empty()) {
                bool has_all = true;
                for (const auto& cap : required_caps_) {
                    if (!target.capabilities.count(cap)) { has_all = false; break; }
                }
                if (!has_all) continue;
            }

            const Vec3 target_pos = target.world_pose.position();
            const Vec3 diff = target_pos - agent_pos;
            const double dist = diff.norm();

            // Detection Volume
            if (!in_detection_volume(diff, dist, forward)) continue;

            // LoS — останавливаем луч чуть раньше цели чтобы не попасть в её bounding
            if (dist > 1e-6) {
                double safe_dist = dist - target.bounding.radius * 2.0 - 0.05;
                if (safe_dist < 0.1) safe_dist = 0.1;
                Ray ray{agent_pos, diff.normalized(), safe_dist};
                RaycastResult res = raycast_->cast(ray);
                if (res.hit && res.distance < safe_dist - 0.05)
                    continue;
            }

            AgentDetection det;
            det.target_id = target.id;
            det.distance  = dist;

            // Relative pose
            Vec3 local_vec = R_obs.transpose() * diff;
            det.relative_pose.x     = local_vec.x();
            det.relative_pose.y     = local_vec.y();
            det.relative_pose.z     = local_vec.z();
            det.relative_pose.yaw   = std::atan2(local_vec.y(), local_vec.x());
            det.relative_pose.pitch = std::atan2(-local_vec.z(),
                std::sqrt(local_vec.x()*local_vec.x() + local_vec.y()*local_vec.y()));

            // Bounding extents
            if (target.bounding.type == ShapeType::SPHERE) {
                double d = target.bounding.radius * 2.0;
                det.bounding_extents = Vec3{d, d, d};
            } else {
                det.bounding_extents = target.bounding.size * 2.0;
            }

            // Relative velocity
            Eigen::Matrix3d R_target = CollisionSystem::rotation_from_pose(target.world_pose);
            Vec3 target_world_vel = R_target * target.world_velocity.linear;
            Vec3 obs_world_vel    = R_obs * agent.world_velocity.linear;
            det.relative_velocity = R_obs.transpose() * (target_world_vel - obs_world_vel);

            data.detections.push_back(std::move(det));
        }

        agent.state.emplace<AgentDetectionData>(std::move(data));
    }

    std::string to_json() const override { return "{}"; }

    void contribute_snapshot(nlohmann::json& out, const Agent& agent) const override {
        const auto* data = agent.state.get<AgentDetectionData>();
        if (!data) return;
        nlohmann::json arr = nlohmann::json::array();
        for (const auto& d : data->detections) {
            arr.push_back({
                {"agent_id", d.target_id},
                {"distance", d.distance},
                {"x", d.relative_pose.x}, {"y", d.relative_pose.y}, {"z", d.relative_pose.z},
                {"vx", d.relative_velocity.x()}, {"vy", d.relative_velocity.y()}
            });
        }
        out["agent_detections"] = arr;
    }

private:
    bool in_detection_volume(const Vec3& diff, double dist, const Vec3& forward) const {
        if (volume_type_ == "sphere")
            return dist <= detection_range_;
        if (volume_type_ == "cone") {
            if (dist > detection_range_) return false;
            if (dist < 1e-9) return true;
            return diff.normalized().dot(forward) >= fov_half_cos_;
        }
        if (volume_type_ == "cylinder") {
            double h2 = diff.x()*diff.x() + diff.y()*diff.y();
            return h2 <= detection_range_*detection_range_
                && std::abs(diff.z()) <= cylinder_half_height_;
        }
        return false;
    }

    std::string  volume_type_{"sphere"};
    double       detection_range_{10.0};
    double       fov_half_cos_{-1.0};
    double       cylinder_half_height_{2.0};
    double       publish_rate_hz_{5.0};
    double       publish_timer_{0.0};
    uint64_t     seq_{0};
    std::vector<std::string> required_caps_;

    const RaycastEngine*      raycast_{nullptr};
    const std::vector<Agent>* agents_{nullptr};
};

} // namespace s2::plugins
```
