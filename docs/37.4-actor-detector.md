# Задача 37.4 — ActorDetectorPlugin — детекция акторов

## Цель

Плагин-наблюдатель: агент видит акторов (двери, пешеходы, конвейеры, лифты) в Detection Volume.
Помимо позиции и bounding box, результат содержит `current_state` актора — текущее состояние FSM.
Это позволяет агенту принимать решения: "дверь открыта → можно проехать", "пешеход движется → объехать".

## Зависимости

- Задача 37.3 (AgentDetectorPlugin — паттерн `set_agents` → аналогично `set_actors`)
- Задача 32 (Actor base + DoorBehavior) — акторы существуют в мире

## Концепт: особенности детекции акторов

### Чем актор отличается от агента (для детектора)

| | Agent | Actor |
|--|-------|-------|
| Есть velocity | Да | Нет (акторы статичны или двигаются через FSM) |
| Есть capabilities | Да | Нет |
| Есть bounding | CollisionShape | CollisionShape |
| Есть current_state | Нет | Да (FSM) |
| Фильтрация | по capabilities | по actor type (строка) |

Actor имеет поле `name` — строковый тип (например `"door"`, `"pedestrian"`, `"conveyor"`).
Детектор фильтрует по нему через `target_actor_type`.

### current_state как ключевые данные

Состояние FSM — строка (`ActorState = std::string`). Примеры:
- Дверь: `"closed"`, `"opening"`, `"open"`, `"closing"`
- Пешеход: `"idle"`, `"walking"`, `"running"`, `"stopped"`
- Конвейер: `"running"`, `"stopped"`, `"reversed"`

Агент-плановщик использует `current_state` для принятия решений.
Это критически важные данные — именно ради них ActorDetector существует как отдельный плагин.

### LoS для акторов

Акторы имеют `collision: CollisionShape`. Они добавляются в динамическую геометрию?
Нет — акторы не являются частью `dynamic_prims_` для RaycastEngine (это только агенты).
Поэтому для LoS актора берём луч от агента до центра актора с `max_range = dist - epsilon`.
Попадание в статическую стену → заблокировано.
Сам актор (дверь, стена-актор) не блокирует луч к себе — аналогично ArUco маркерам.

**Исключение:** если актор является физической стеной (например закрытая дверь добавляется
в статическую геометрию при состоянии "closed"), то raycast это учтёт автоматически.
Но это логика задачи 32, не данной задачи.

### target_actor_type

Параметр конфигурации — строка или пустая (видеть всех):
```yaml
target_actor_type: "door"       # только двери
target_actor_type: "pedestrian" # только пешеходы
target_actor_type: ""           # все акторы
```

Сравниваем с `actor.name` (или отдельным полем type — зависит от реализации задачи 32).
В текущей `actor.hpp` есть только `name` — используем его как type для фильтрации.

## Что сделать

### 1. Типы результата

**Файл:** `workspace/s2_core/include/s2/sensor_data.hpp`

```cpp
/**
 * @brief Одно обнаружение актора.
 *
 * actor_type: тип актора (actor.name — "door", "pedestrian", ...)
 * current_state: текущее состояние FSM ("open", "walking", ...)
 * relative_pose: поза в системе координат тела наблюдателя
 * bounding_extents: полные размеры bounding box [м]
 * distance: расстояние [м]
 */
struct ActorDetection {
    ActorId     actor_id{0};
    std::string actor_type;
    std::string current_state;
    Pose3D      relative_pose;
    Vec3        bounding_extents{Vec3::Zero()};
    double      distance{0.0};
};

struct ActorDetectionData {
    uint64_t seq{0};
    std::vector<ActorDetection> detections;
};
```

### 4. ActorDetectorPlugin

**Файл:** `workspace/s2_plugins/include/s2/plugins/actor_detector.hpp` (новый)

```cpp
#pragma once

#include <s2/plugin_base.hpp>
#include <s2/actor.hpp>
#include <s2/sensor_data.hpp>
#include <s2/collision_system.hpp>
#include <s2/raycast_engine.hpp>
#include <yaml-cpp/yaml.h>

namespace s2::plugins {

/**
 * @brief Плагин-детектор акторов (двери, пешеходы, конвейеры).
 *
 * Ключевое отличие от AgentDetector: возвращает current_state FSM актора,
 * что позволяет агенту знать не только ГДЕ актор, но и в каком он состоянии.
 *
 * Параметры:
 *  - target_actor_type: фильтр по типу ("door", "pedestrian", "" = все)
 *  - volume_type, detection_range, fov_angle, cylinder_half_height
 *  - publish_rate_hz
 */
class ActorDetectorPlugin : public IAgentPlugin {
public:
    std::string type() const override { return "actor_detector"; }

    void from_config(const YAML::Node& node) override {
        volume_type_       = node["volume_type"].as<std::string>("sphere");
        detection_range_   = node["detection_range"].as<double>(8.0);
        target_actor_type_ = node["target_actor_type"].as<std::string>("");
        publish_rate_hz_   = node["publish_rate_hz"].as<double>(5.0);

        double fov_deg = node["fov_angle"].as<double>(360.0);
        fov_half_cos_  = std::cos((fov_deg / 2.0) * M_PI / 180.0);

        cylinder_half_height_ = node["cylinder_half_height"].as<double>(2.0);
    }

    void set_raycast_engine(const RaycastEngine* e) override { raycast_ = e; }
    void set_actors(const std::vector<Actor>* a) override { actors_ = a; }

    void update(double dt, Agent& agent) override {
        publish_timer_ += dt;
        if (publish_rate_hz_ > 0 && publish_timer_ < 1.0 / publish_rate_hz_)
            return;
        publish_timer_ = 0.0;

        ActorDetectionData data;
        data.seq = seq_++;

        if (!actors_ || !raycast_) {
            agent.state.emplace<ActorDetectionData>(std::move(data));
            return;
        }

        const Vec3 agent_pos = agent.world_pose.position();
        const Eigen::Matrix3d R_obs = CollisionSystem::rotation_from_pose(agent.world_pose);
        const Vec3 forward = R_obs * Vec3(1.0, 0.0, 0.0);

        for (const auto& actor : *actors_) {
            // Фильтр по типу (name актора)
            if (!target_actor_type_.empty() && actor.name != target_actor_type_)
                continue;

            const Vec3 target_pos = actor.world_pose.position();
            const Vec3 diff = target_pos - agent_pos;
            const double dist = diff.norm();

            if (!in_detection_volume(diff, dist, forward)) continue;

            // LoS — луч до центра актора
            if (dist > 1e-6) {
                const double LOS_EPSILON = 0.05;
                Ray ray{agent_pos, diff.normalized(), dist - LOS_EPSILON};
                RaycastResult res = raycast_->cast(ray);
                if (res.hit && res.distance < dist - LOS_EPSILON - 0.05)
                    continue;
            }

            ActorDetection det;
            det.actor_id     = actor.id;
            det.actor_type   = actor.name;
            det.current_state = actor.current_state;
            det.distance     = dist;

            // Relative pose
            Vec3 local_vec = R_obs.transpose() * diff;
            det.relative_pose.x     = local_vec.x();
            det.relative_pose.y     = local_vec.y();
            det.relative_pose.z     = local_vec.z();
            det.relative_pose.yaw   = std::atan2(local_vec.y(), local_vec.x());
            det.relative_pose.pitch = std::atan2(-local_vec.z(),
                std::sqrt(local_vec.x()*local_vec.x() + local_vec.y()*local_vec.y()));

            // Bounding extents
            if (actor.collision.type == ShapeType::SPHERE) {
                double d = actor.collision.radius * 2.0;
                det.bounding_extents = Vec3{d, d, d};
            } else if (actor.collision.type == ShapeType::CYLINDER) {
                det.bounding_extents = Vec3{
                    actor.collision.radius * 2.0,
                    actor.collision.radius * 2.0,
                    actor.collision.height
                };
            } else {
                det.bounding_extents = actor.collision.size * 2.0;
            }

            data.detections.push_back(std::move(det));
        }

        agent.state.emplace<ActorDetectionData>(std::move(data));
    }

    std::string to_json() const override { return "{}"; }

    void contribute_snapshot(nlohmann::json& out, const Agent& agent) const override {
        const auto* data = agent.state.get<ActorDetectionData>();
        if (!data) return;
        nlohmann::json arr = nlohmann::json::array();
        for (const auto& d : data->detections) {
            arr.push_back({
                {"actor_id",      d.actor_id},
                {"actor_type",    d.actor_type},
                {"current_state", d.current_state},
                {"distance",      d.distance},
                {"x", d.relative_pose.x},
                {"y", d.relative_pose.y}
            });
        }
        out["actor_detections"] = arr;
    }

private:
    bool in_detection_volume(const Vec3& diff, double dist, const Vec3& forward) const {
        if (volume_type_ == "sphere") return dist <= detection_range_;
        if (volume_type_ == "cone") {
            if (dist > detection_range_) return false;
            if (dist < 1e-9) return true;
            return diff.normalized().dot(forward) >= fov_half_cos_;
        }
        if (volume_type_ == "cylinder") {
            double h2 = diff.x()*diff.x() + diff.y()*diff.y();
            return h2 <= detection_range_*detection_range_
                && std::abs(diff.z()) <= cylinder_half_height_;
        }
        return false;
    }

    std::string  volume_type_{"sphere"};
    double       detection_range_{8.0};
    double       fov_half_cos_{-1.0};
    double       cylinder_half_height_{2.0};
    std::string  target_actor_type_;
    double       publish_rate_hz_{5.0};
    double       publish_timer_{0.0};
    uint64_t     seq_{0};

    const RaycastEngine*       raycast_{nullptr};
    const std::vector<Actor>*  actors_{nullptr};
};

} // namespace s2::plugins
```

## Пример YAML

```yaml
agents:
  - name: warehouse_robot
    plugins:
      # Видит двери в 8 м (чтобы знать открыта ли дверь перед поездкой к ней)
      - type: actor_detector
        target_actor_type: "door"
        volume_type: sphere
        detection_range: 8.0
        publish_rate_hz: 5.0

      # Отдельный детектор для пешеходов в конусе вперёд
      - type: actor_detector
        target_actor_type: "pedestrian"
        volume_type: cone
        detection_range: 6.0
        fov_angle: 120.0
        publish_rate_hz: 10.0
```
