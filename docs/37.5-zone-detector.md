# Задача 37.5 — ZoneDetectorPlugin — детекция зон по типу

## Цель

Плагин-наблюдатель: агент видит зоны определённого типа в пространстве — даже не находясь в них.
Результат — точные геометрические параметры зоны: центр, форма, размер, нормаль (для FLAT).
Это позволяет агенту планировать маршруты (объехать зону льда), реагировать заблаговременно
(замедлиться перед туманной зоной) или строить карту среды.

## Концепт: детекция зон как видимых объектов

### Принципиальное отличие от "нахождения в зоне"

Текущая система: ZoneSystem знает, **какие агенты внутри каждой зоны**.
ZoneDetector — инверсия: агент знает, **какие зоны видны ему снаружи**.

```
ZoneSystem:        Зона → замечает агентов внутри → применяет эффект
ZoneDetector:  Агент → замечает зоны снаружи → получает их параметры
```

Агент может обнаружить зону **до того как в неё войдёт**. Это ключевая возможность.

### Что значит "видеть зону"

LoS для зоны проверяется от агента до **центра зоны**.
Если центр зоны виден (нет стены на прямой) — зона считается обнаруженной.

Это упрощение: зона может быть очень большой и частично закрытой стеной.
Проверка только центра даёт детерминированный результат без raycast-sampling.

Edge case — агент внутри зоны: центр зоны может быть прямо под агентом (dist ≈ 0).
В этом случае LoS пропускаем (dist < epsilon → считаем что виден).
Агент внутри зоны всё равно её "видит".

### Точные геометрические параметры

В отличие от гипотетической вероятностной надстройки, базовый ZoneDetector возвращает
**точные параметры** — те, что хранятся в `Zone.shape`:

```
ZoneDetection {
    zone_id,            // строковый ID зоны
    zone_effect_type,   // тип эффекта ("ice_modifier", "charging", "fog", ...)
    shape_type,         // SPHERE/AABB/CYLINDER/FLAT/INFINITE
    center,             // Vec3 — центр зоны в мировых координатах
    radius,             // для SPHERE и CYLINDER
    half_size,          // для AABB
    half_height,        // для CYLINDER
    flat_normal,        // Vec3 — нормаль (только для FLAT зон)
    flat_contact_epsilon, // только для FLAT зон
    distance,           // расстояние от агента до центра зоны [м]
}
```

Это всё что нужно агенту для планирования: он знает точно где зона и какой она формы.

### Фильтрация по типу эффекта

`target_effect_type: "ice_modifier"` — детектор видит только зоны с эффектом ice_modifier.

Зона может иметь несколько эффектов (`effects` — вектор). Для фильтрации проверяем:
есть ли хотя бы один эффект с нужным типом:
```cpp
bool matches = target_effect_type_.empty();
if (!matches) {
    for (const auto& eff : zone.effects) {
        if (eff.type == target_effect_type_) { matches = true; break; }
    }
}
```

### Detection Volume для зон

Для зоны проверяем нахождение её **центра** в Detection Volume агента.
Это симметрично с AgentDetector/ActorDetector — проверяем одну характерную точку.

Потенциальный вопрос: большая зона может иметь центр вне Detection Volume,
но часть зоны пересекать Detection Volume. Для v1 детектируем только по центру —
это просто и детерминировано. Детекция "по пересечению" — возможная надстройка в будущем.

### Передача зон: set_zones

Зоны живут в `ZoneSystem`, не в `SimWorld`. Поэтому передаём через
`zone_system_.all_zones()` — это константная ссылка на внутренний вектор.

`ZoneSystem::all_zones()` уже существует как метод. Новый метод в IAgentPlugin:
```cpp
virtual void set_zones(const std::vector<Zone>*) {}
```

SimEngine передаёт `&zone_system_.all_zones()` — но `all_zones()` возвращает const ref,
нам нужен указатель на внутренний вектор. Добавим метод `zones_ptr()` или используем
`&zone_system_.all_zones()[0]` — нет, лучше добавить метод в ZoneSystem.

## Что сделать

### 1. Типы результата

**Файл:** `workspace/s2_core/include/s2/sensor_data.hpp`

```cpp
/**
 * @brief Одно обнаружение зоны.
 *
 * zone_effect_type: тип эффекта первого эффекта зоны.
 *   Используется для идентификации "что это за зона" ("ice_modifier", "fog", ...).
 * shape_type: строковое представление формы ("sphere", "aabb", "cylinder", "flat", "infinite")
 * center: центр зоны в мировых координатах
 * radius: для sphere и cylinder
 * half_size: для aabb (половинные размеры)
 * half_height: для cylinder (полувысота по Z)
 * flat_normal: нормаль к плоскости (только для flat зон)
 * flat_contact_epsilon: допуск касания (только для flat зон)
 * distance: расстояние от агента до центра зоны [м]
 */
struct ZoneDetection {
    ZoneId      zone_id;
    std::string zone_effect_type;
    std::string shape_type;
    Vec3        center{Vec3::Zero()};
    double      radius{0.0};
    Vec3        half_size{Vec3::Zero()};
    double      half_height{0.0};
    Vec3        flat_normal{0.0, 0.0, 1.0};
    double      flat_contact_epsilon{0.05};
    double      distance{0.0};
};

struct ZoneDetectionData {
    uint64_t seq{0};
    std::vector<ZoneDetection> detections;
};
```

### 5. ZoneDetectorPlugin

**Файл:** `workspace/s2_plugins/include/s2/plugins/zone_detector.hpp` (новый)

```cpp
#pragma once

#include <s2/plugin_base.hpp>
#include <s2/zone.hpp>
#include <s2/sensor_data.hpp>
#include <s2/collision_system.hpp>
#include <s2/raycast_engine.hpp>
#include <yaml-cpp/yaml.h>
#include <string>

namespace s2::plugins {

/**
 * @brief Плагин-детектор зон.
 *
 * Видит зоны заданного типа в Detection Volume. Возвращает точные
 * геометрические параметры зоны — центр, форма, нормаль для FLAT.
 *
 * Агент не обязан находиться внутри зоны чтобы её обнаружить.
 * Это позволяет планировать маршруты заблаговременно.
 *
 * Параметры:
 *  - target_effect_type: тип эффекта для фильтрации ("ice_modifier", "fog", "" = все)
 *  - volume_type, detection_range, fov_angle — Detection Volume
 *  - publish_rate_hz
 */
class ZoneDetectorPlugin : public IAgentPlugin {
public:
    std::string type() const override { return "zone_detector"; }

    void from_config(const YAML::Node& node) override {
        volume_type_        = node["volume_type"].as<std::string>("sphere");
        detection_range_    = node["detection_range"].as<double>(12.0);
        target_effect_type_ = node["target_effect_type"].as<std::string>("");
        publish_rate_hz_    = node["publish_rate_hz"].as<double>(2.0);

        double fov_deg = node["fov_angle"].as<double>(360.0);
        fov_half_cos_  = std::cos((fov_deg / 2.0) * M_PI / 180.0);

        cylinder_half_height_ = node["cylinder_half_height"].as<double>(5.0);
    }

    void set_raycast_engine(const RaycastEngine* e) override { raycast_ = e; }
    void set_zones(const std::vector<Zone>* z) override { zones_ = z; }

    void update(double dt, Agent& agent) override {
        publish_timer_ += dt;
        if (publish_rate_hz_ > 0 && publish_timer_ < 1.0 / publish_rate_hz_)
            return;
        publish_timer_ = 0.0;

        ZoneDetectionData data;
        data.seq = seq_++;

        if (!zones_ || !raycast_) {
            agent.state.emplace<ZoneDetectionData>(std::move(data));
            return;
        }

        const Vec3 agent_pos = agent.world_pose.position();
        const Eigen::Matrix3d R_obs = CollisionSystem::rotation_from_pose(agent.world_pose);
        const Vec3 forward = R_obs * Vec3(1.0, 0.0, 0.0);

        for (const auto& zone : *zones_) {
            if (!zone.enabled) continue;

            // Фильтр по типу эффекта
            if (!target_effect_type_.empty()) {
                bool found = false;
                for (const auto& eff : zone.effects) {
                    if (eff.type == target_effect_type_) { found = true; break; }
                }
                if (!found) continue;
            }

            // Для INFINITE зон — расстояние считаем 0, всегда "видны"
            if (zone.shape.type == ZoneShapeType::INFINITE) {
                data.detections.push_back(make_detection(zone, 0.0));
                continue;
            }

            const Vec3 zone_center = zone.shape.center;
            const Vec3 diff = zone_center - agent_pos;
            const double dist = diff.norm();

            // Detection Volume (по центру зоны)
            if (!in_detection_volume(diff, dist, forward)) continue;

            // LoS до центра зоны
            // Если агент внутри зоны (dist ≈ 0) — пропускаем LoS (всегда виден)
            if (dist > 0.5) {
                const double LOS_EPSILON = 0.05;
                Ray ray{agent_pos, diff.normalized(), dist - LOS_EPSILON};
                RaycastResult res = raycast_->cast(ray);
                if (res.hit && res.distance < dist - LOS_EPSILON - 0.05)
                    continue;  // центр зоны за стеной
            }

            data.detections.push_back(make_detection(zone, dist));
        }

        agent.state.emplace<ZoneDetectionData>(std::move(data));
    }

    std::string to_json() const override { return "{}"; }

    void contribute_snapshot(nlohmann::json& out, const Agent& agent) const override {
        const auto* data = agent.state.get<ZoneDetectionData>();
        if (!data) return;
        nlohmann::json arr = nlohmann::json::array();
        for (const auto& d : data->detections) {
            arr.push_back({
                {"zone_id",     d.zone_id},
                {"effect_type", d.zone_effect_type},
                {"shape",       d.shape_type},
                {"distance",    d.distance},
                {"cx", d.center.x()}, {"cy", d.center.y()}, {"cz", d.center.z()}
            });
        }
        out["zone_detections"] = arr;
    }

private:
    ZoneDetection make_detection(const Zone& zone, double dist) const {
        ZoneDetection d;
        d.zone_id   = zone.id;
        d.distance  = dist;
        d.center    = zone.shape.center;
        d.radius    = zone.shape.radius;
        d.half_size = zone.shape.half_size;
        d.half_height = zone.shape.half_height;

        // Тип эффекта: первый из списка (или пустой если нет эффектов)
        d.zone_effect_type = zone.effects.empty() ? "" : zone.effects[0].type;

        switch (zone.shape.type) {
            case ZoneShapeType::SPHERE:   d.shape_type = "sphere";   break;
            case ZoneShapeType::AABB:     d.shape_type = "aabb";     break;
            case ZoneShapeType::CYLINDER: d.shape_type = "cylinder"; break;
            case ZoneShapeType::INFINITE: d.shape_type = "infinite"; break;
            case ZoneShapeType::FLAT:
                d.shape_type            = "flat";
                d.flat_normal           = zone.shape.normal;
                d.flat_contact_epsilon  = zone.shape.contact_epsilon;
                break;
        }
        return d;
    }

    bool in_detection_volume(const Vec3& diff, double dist, const Vec3& forward) const {
        if (volume_type_ == "sphere") return dist <= detection_range_;
        if (volume_type_ == "cone") {
            if (dist > detection_range_) return false;
            if (dist < 1e-9) return true;
            return diff.normalized().dot(forward) >= fov_half_cos_;
        }
        if (volume_type_ == "cylinder") {
            double h2 = diff.x()*diff.x() + diff.y()*diff.y();
            return h2 <= detection_range_*detection_range_
                && std::abs(diff.z()) <= cylinder_half_height_;
        }
        return false;
    }

    std::string  volume_type_{"sphere"};
    double       detection_range_{12.0};
    double       fov_half_cos_{-1.0};
    double       cylinder_half_height_{5.0};
    std::string  target_effect_type_;
    double       publish_rate_hz_{2.0};
    double       publish_timer_{0.0};
    uint64_t     seq_{0};

    const RaycastEngine*    raycast_{nullptr};
    const std::vector<Zone>* zones_{nullptr};
};

} // namespace s2::plugins
```

## Пример YAML

```yaml
agents:
  - name: path_planner_robot
    plugins:
      # Видит ледяные зоны в 15 м (для планирования объезда)

        target_effect_type: "ice_modifier"
        volume_type: sphere
        detection_range: 15.0
        publish_rate_hz: 1.0     # редко — зоны статичны

      # Видит туман — чтобы знать когда снижается видимость

        target_effect_type: "fog"
        volume_type: sphere
        detection_range: 20.0
        publish_rate_hz: 2.0

      # Дрон видит зарядные станции сверху (цилиндр вниз)
      - type: zone_detector
        target_effect_type: "charging"
        volume_type: cylinder
        detection_range: 10.0
        cylinder_half_height: 8.0
        publish_rate_hz: 1.0
```
