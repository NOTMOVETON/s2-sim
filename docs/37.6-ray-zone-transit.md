# Задача 37.6 — Транзитный sensor_mod через луч

## Цель

Расширить LoS-проверку в детекторах (37.2–37.5): луч, брошенный от агента к цели,
может проходить через SENSOR-зоны. Если зона влияет на параметры сенсора и агент
**не находится** в этой зоне — её эффект применяется к данному конкретному лучу.

Это физически правдоподобно: туман **между** агентом и маркером ухудшает видимость,
даже если агент сам стоит в ясной погоде.

## Зависимости

- Задача 31 (SensorMod, SensorModResolver — механизм модификаций сенсоров)
- Задача 37.2–37.5 (детектор-плагины, используют LoS)
- Задача 37.1 (FLAT зоны — их тоже нужно уметь пересекать лучом)

## Концепт: как луч взаимодействует с зоной

### Почему не двойной счёт

Существующий механизм (задача 31): ZoneSystem собирает `sensor_mods` всех активных зон,
в которых **находится** агент, и применяет их глобально перед вызовом плагинов.

Транзитный эффект: зона не вокруг агента, а **на пути луча**. Агент снаружи туманной зоны.

Условие "не двойной счёт":
```
зона влияет транзитно ТОЛЬКО если agent_id ∉ zone.inside_agents
```

Если агент уже внутри зоны → её `sensor_mods` уже применены глобально через задачу 31
→ транзитный эффект не добавляется.

### Ray-zone intersection

Для каждой SENSOR-зоны на пути луча вычисляем пересечение луча с геометрией зоны.

**Пересечение луча со сферой:**
```
// Квадратное уравнение: |origin + t*dir - center|² = radius²
Vec3 oc = origin - sphere_center
a = dir.dot(dir)  // = 1 если dir нормализован
b = 2 * oc.dot(dir)
c = oc.dot(oc) - radius²
D = b² - 4ac
if D < 0: нет пересечения
t1 = (-b - sqrt(D)) / 2a
t2 = (-b + sqrt(D)) / 2a
// Луч пересекает [t1, t2], оба должны быть в диапазоне [0, ray.max_range]
```

**Пересечение луча с AABB:**
```
// Slab method — пересечение с 3 парами плоскостей
t_enter = max(t_xmin, t_ymin, t_zmin)
t_exit  = min(t_xmax, t_ymax, t_zmax)
пересечение если t_enter < t_exit && t_exit > 0 && t_enter < ray.max_range
```

**Пересечение луча с цилиндром (ось Z):**
```
// Горизонтальная часть: пересечение с бесконечным цилиндром
// Вертикальная часть: зажать по [center.z - half_height, center.z + half_height]
dx = dir.x(), dy = dir.y()
ox = origin.x() - center.x(), oy = origin.y() - center.y()
a = dx*dx + dy*dy
b = 2*(ox*dx + oy*dy)
c = ox*ox + oy*oy - radius²
// ... аналогично сфере, потом проверка Z
```

**Пересечение луча с FLAT зоной:**
```
// Луч пересекает плоскость normal·(P - center) = 0
denom = dir.dot(normal)
if |denom| < epsilon: луч параллелен плоскости → нет пересечения
t = (center - origin).dot(normal) / denom
if t < 0 || t > ray.max_range: нет пересечения
// Проверяем что точка пересечения внутри 2D формы
hit_point = origin + t * dir
// ... далее как ZoneShape::contains() для FLAT
```

### Структура результата

LoS-вызов с транзитными зонами возвращает расширенный результат:

```cpp
struct RayWithZonesResult {
    bool   hit{false};          // попал в стену/коллизию?
    double collision_distance;  // расстояние до стены (если hit)
    std::vector<EffectPlugin::SensorMod> transit_mods;  // суммарные моды от транзитных зон
};
```

### Применение transit_mods в детекторе

После получения `RayWithZonesResult` детектор применяет `transit_mods` к своим параметрам:

```cpp
// Собираем transit_mods через SensorModResolver (уже реализован в задаче 31)
SensorModResolver resolver;
resolver.add(ray_result.transit_mods);

// Применяем к detection_range для этого конкретного луча
double effective_range = resolver.apply("range", detection_range_);

// Если расстояние до цели > effective_range → "не видит" (дальность ухудшена туманом)
if (dist > effective_range) continue;
```

Важно: `transit_mods` применяются **только к одному лучу**, не глобально.
Следующий луч (к другому маркеру) проходит через другой путь и имеет свои моды.

### Порог "луч проходит через зону"

Луч проходит через зону если интервал пересечения `[t_enter, t_exit]` попадает
в `[0, ray.max_range]`. Не нужно чтобы луч полностью пронизывал зону — достаточно
частичного пересечения. Даже тонкий слой тумана на пути снижает дальность.

Формально: зона считается "транзитной" если `t_enter < ray.max_range && t_exit > 0`.

## Что сделать

### 1. ZoneShape: метод intersects_ray

**Файл:** `workspace/s2_core/include/s2/types.hpp`

Добавить в структуру `ZoneShape`:

```cpp
/**
 * @brief Проверить пересечение луча с зоной.
 *
 * Возвращает true если луч (ограниченный ray.max_range) проходит через зону.
 * Используется для определения транзитного воздействия SENSOR-зон.
 *
 * Граничный случай: агент внутри зоны (origin внутри формы) — возвращает true.
 * INFINITE зона: всегда true.
 */
bool intersects_ray(const Ray& ray) const {
    switch (type) {
        case ZoneShapeType::SPHERE: {
            Vec3 oc = ray.origin - center;
            double b = oc.dot(ray.direction);
            double c = oc.dot(oc) - radius * radius;
            double D = b*b - c;
            if (D < 0) return false;
            double sq = std::sqrt(D);
            double t1 = -b - sq;
            double t2 = -b + sq;
            return t2 > 0 && t1 < ray.max_range;
        }
        case ZoneShapeType::AABB: {
            // Slab method
            Vec3 inv_dir = Vec3{1.0/ray.direction.x(), 1.0/ray.direction.y(), 1.0/ray.direction.z()};
            Vec3 t_min = (center - half_size - ray.origin).cwiseProduct(inv_dir);
            Vec3 t_max = (center + half_size - ray.origin).cwiseProduct(inv_dir);
            Vec3 t1 = t_min.cwiseMin(t_max);
            Vec3 t2 = t_min.cwiseMax(t_max);
            double t_enter = t1.maxCoeff();
            double t_exit  = t2.minCoeff();
            return t_enter <= t_exit && t_exit > 0 && t_enter < ray.max_range;
        }
        case ZoneShapeType::CYLINDER: {
            // Горизонтальный тест (как 2D круг)
            double ox = ray.origin.x() - center.x();
            double oy = ray.origin.y() - center.y();
            double dx = ray.direction.x();
            double dy = ray.direction.y();
            double a = dx*dx + dy*dy;
            if (a < 1e-12) {
                // Луч вертикальный — проверяем только Z
                double z1 = center.z() - half_height;
                double z2 = center.z() + half_height;
                double tz1 = (z1 - ray.origin.z()) / ray.direction.z();
                double tz2 = (z2 - ray.origin.z()) / ray.direction.z();
                double t_enter = std::min(tz1, tz2);
                double t_exit  = std::max(tz1, tz2);
                double horiz_d2 = ox*ox + oy*oy;
                return horiz_d2 <= radius*radius && t_exit > 0 && t_enter < ray.max_range;
            }
            double b = 2*(ox*dx + oy*dy);
            double c = ox*ox + oy*oy - radius*radius;
            double D = b*b - 4*a*c;
            if (D < 0) return false;
            double sq = std::sqrt(D);
            double t_xy1 = (-b - sq) / (2*a);
            double t_xy2 = (-b + sq) / (2*a);
            if (t_xy2 < 0 || t_xy1 > ray.max_range) return false;
            // Вертикальный тест
            double tz1 = (center.z() - half_height - ray.origin.z()) / ray.direction.z();
            double tz2 = (center.z() + half_height - ray.origin.z()) / ray.direction.z();
            if (tz1 > tz2) std::swap(tz1, tz2);
            double t_enter = std::max(t_xy1, tz1);
            double t_exit  = std::min(t_xy2, tz2);
            return t_enter <= t_exit && t_exit > 0 && t_enter < ray.max_range;
        }
        case ZoneShapeType::FLAT: {
            double denom = ray.direction.dot(normal);
            if (std::abs(denom) < 1e-9) return false;  // луч параллелен плоскости
            double t = (center - ray.origin).dot(normal) / denom;
            if (t < 0 || t > ray.max_range) return false;
            Vec3 hit_point = ray.origin + t * ray.direction;
            // Используем существующий contains() для 2D теста
            // Временно убираем epsilon-проверку — луч попадает ТОЧНО в плоскость
            return contains_2d_projection(hit_point);
        }
        case ZoneShapeType::INFINITE:
            return true;
        default:
            return false;
    }
}
```

Вспомогательный приватный метод `contains_2d_projection()` — аналог 2D-части `contains()`,
без distance_to_plane теста (луч попадает точно в плоскость).

### 2. ZoneSystem: метод collect_transit_mods

**Файл:** `workspace/s2_core/include/s2/zone_system.hpp`

```cpp
/**
 * @brief Собрать sensor_mods от SENSOR-зон, через которые проходит луч.
 *
 * Только зоны типа SENSOR (EffectType::SENSOR).
 * Только если agent_id НЕ в zone.inside_agents (защита от двойного счёта).
 *
 * @param ray    Луч (origin, direction, max_range)
 * @param agent_id  ID агента, бросающего луч
 * @param sim_time  Текущее время симуляции (для EffectContext)
 * @return SensorModResolver с накопленными модификациями
 */
SensorModResolver collect_transit_mods(const Ray& ray, AgentId agent_id,
                                        double sim_time) const
{
    SensorModResolver resolver;

    for (const auto& zone : zones_) {
        if (!zone.enabled) continue;
        // Только SENSOR-эффекты имеют смысл для транзитного воздействия
        bool has_sensor_effect = false;
        for (const auto& eff : zone.effects)
            if (eff.effect_type == EffectType::SENSOR) { has_sensor_effect = true; break; }
        if (!has_sensor_effect) continue;

        // Защита от двойного счёта: агент уже в зоне → глобальные моды уже применены
        if (zone.inside_agents.count(agent_id)) continue;

        // Пересекает ли луч геометрию зоны?
        if (!zone.shape.intersects_ray(ray)) continue;

        // Собрать sensor_mods от всех SENSOR-эффектов этой зоны
        EffectContext ctx;
        ctx.sim_time       = sim_time;
        ctx.dt             = 0.0;   // transit не использует dt
        ctx.zone_id        = zone.id;
        ctx.zone_center    = zone.shape.center;
        ctx.agent_id       = agent_id;
        ctx.agent_position = ray.origin;

        for (const auto& eff : zone.effects) {
            if (eff.effect_type != EffectType::SENSOR) continue;
            if (!eff.plugin) continue;
            resolver.add(eff.plugin->sensor_mods(ctx));
        }
    }

    return resolver;
}
```

### 3. Обновить LoS в детекторах (37.2–37.5)

Каждый detector-плагин получает дополнительный метод `set_zone_system()` или
использует уже переданный указатель на зоны.

Но `collect_transit_mods` требует `ZoneSystem`, а не просто `std::vector<Zone>`.
Поэтому добавляем новый метод в `IAgentPlugin`:

**Файл:** `workspace/s2_core/include/s2/plugin_base.hpp`

```cpp
// Forward declaration:
namespace s2 { class ZoneSystem; }

// В теле IAgentPlugin:
/**
 * @brief Передать указатель на ZoneSystem для транзитных sensor_mods.
 * Используется детекторами в задаче 37.6.
 */

```

**Файл:** `workspace/s2_core/include/s2/sim_engine.hpp`, фаза 3e:

```cpp
plugin->set_zone_system(&zone_system_);    // НОВОЕ (37.6)
```

### 4. Обновить ArucoDetectorPlugin (пример для всех детекторов)

В методе `update()`, в блоке LoS:

```cpp
// Было:
Ray ray{agent_pos, direction, dist};
RaycastResult res = raycast_->cast(ray);
if (res.hit && res.distance < dist - LOS_EPSILON) continue;

// Стало:
Ray ray{agent_pos, direction, dist};
RaycastResult res = raycast_->cast(ray);
if (res.hit && res.distance < dist - LOS_EPSILON) continue;  // стена блокирует

// Транзитные sensor_mods от зон на пути луча
double effective_range = detection_range_;
if (zone_system_) {
    SensorModResolver resolver = zone_system_->collect_transit_mods(ray, agent.id, sim_time_);
    effective_range = resolver.apply("range", detection_range_);
    // Если дальность ухудшилась и цель теперь "за пределами" — пропускаем
    if (dist > effective_range) continue;
}
```

Аналогично обновляются `AgentDetectorPlugin`, `ActorDetectorPlugin`, `ZoneDetectorPlugin`.

## Пример YAML

```yaml
zones:
  # Туманная зона между роботом и маркером
  - id: "fog_patch"
    shape:
      type: sphere
      center: {x: 5.0, y: 0.0, z: 0.5}
      radius: 2.0
    color: "#CCCCCC"
    opacity: 0.3
    effects:
      - type: fog
        params:
          range_multiplier: 0.3    # дальность лучей × 0.3 при прохождении через зону

aruco_markers:
  - id: 42
    pose: {x: 10.0, y: 0.0, z: 0.5}   # маркер за туманной зоной

agents:
  - name: robot
    pose: {x: 0.0, y: 0.0, z: 0.0}
    plugins:
      - type: aruco_detector
        volume_type: sphere
        detection_range: 12.0    # без тумана видит до 12 м
        # С туманом (range × 0.3 = 3.6 м):
        # маркер в 10 м → 10 > 3.6 → не виден
        # Если туман убрать: 10 < 12 → виден
```
